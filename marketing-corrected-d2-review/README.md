# Bites2B compact symbol

Faithful static reproduction of the supplied screenshot: one tilted coral B with a bite at its upper-right edge and the blue number 2 centered inside. Transparent SVG master; no square, border or separate blue B.

The original complete symbol was not present in the repository or public preview assets. The B and 2 contours come from the approved PR #35 vector source at commit 283ba42c6a0bf0fdde70ec44c7d03b38d0e612cd, docs/marketing-preview/wordmark-intro-d/index.html. The screenshot supplied with the request guided the composition and relative placement. The older square B-only PNG was checked as a silhouette reference, not reused as the output.
